# Компьютерное зрение, 4 курс, 2026

Практический курс для 4 курса бакалавриата. Вы пройдёте путь от изображения как массива чисел до дообучения YOLO, U-Net и zero-shot моделей вроде SAM и CLIP.
Все работы делаются на одном датасете, [Oxford-IIIT Pet](https://www.robots.ox.ac.uk/~vgg/data/pets/) (37 пород кошек и собак), у каждого студента свой вариант пород. Сдача работ через ваш личный репозиторий на GitHub.

## Быстрый старт

1. **Аккаунты.** Заведите аккаунт на [Colab](https://colab.research.google.com) и на [Kaggle](https://www.kaggle.com/account/login?phase=startRegisterTab). 
2. **Свой репозиторий.** Создайте публичный репозиторий `cv-2026-familiya` (фамилия латиницей, строчными) и положите в него файлы из [templates/student-repo/](templates/student-repo/). Пошагово: [docs/git.md](docs/git.md).
3. **Среда.** Откройте ноутбук в Kaggle, в Colab или поставьте Python локально: [docs/setup.md](docs/setup.md).
4. **Данные варианта.** Номер варианта равен вашему номеру в списке группы. Скачайте свои данные командой `python data/get_data.py --variant N` из корня этого репозитория. Подробно: [data/README.md](data/README.md).

## Как сдавать

- Один публичный репозиторий `cv-2026-familiya` на весь семестр, в нём папки `lab01` … `lab06`.
- В каждой папке лежит `README.md` с пятью разделами: задача, как запустить, данные, результаты, выводы.
- Работа считается сданной в момент последнего коммита в её папку. Сообщение в чат сдачей не считается.
- Лаба стоит 7 баллов. За выступление на открытом разборе лабы дают +3 бонусных балла, всего бонусов до 18. Подробности: [Правила курса](Правила%20курса.md), разделы 4–6.
